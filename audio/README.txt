Background music for the site.

Currently playing: music.mp3
  Elvis Presley - "Can't Help Falling in Love"  (3:03, 128 kbps, 2.8 MB)

To change the song, replace music.mp3 with another MP3 using that exact
filename. The player picks it up automatically -- no code changes needed.
Remove the file and the music button disappears; the site never shows a
broken control.

How it behaves:
 - Starts when a guest taps "Open Invitation" (browsers only allow sound
   to begin after a real tap or click).
 - Plays at 35% volume and loops.
 - Guests can turn it off with the button in the bottom-right corner.

Two things to keep in mind:
 - Size: guests on mobile data download this file. Under ~3 MB is sensible.
 - Rights: this is a commercially released song, so it is copyrighted.
   That is common and low-risk for a personal invitation link, but if the
   site is ever indexed publicly or a host objects, swap in a royalty-free
   instrumental.
